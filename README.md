# 🧮 Python Scientific Calculator

An interactive **Scientific Calculator** built using **Python**, **HTML**, **CSS**, and **JavaScript**.
It supports both **console-based operations** (Python CLI) and a **modern web interface** for easy computation and visualization.

---

## 🚀 Features

* 🔢 **Basic Operations:** Addition, Subtraction, Multiplication, Division
* 📐 **Trigonometric Functions:** sin, cos, tan (in degrees)
* 🧮 **Scientific Functions:** Natural log, log₁₀, factorial, power
* 💡 **Web GUI:** Neon-themed calculator with glowing animations
* ⚙️ **Error Handling:** Manages invalid input and division by zero
* 🖥️ **Cross-Platform:** Works on console and browser

---

## 🧠 Project Overview

This project demonstrates how **Python’s math library** and **frontend web technologies** can work together to create a hybrid scientific calculator.

* **`sl_project.py`** → Console-based calculator (Python)
* **`scientific_calculator.html`** → Web-based GUI calculator

Both versions provide accurate and responsive results with a focus on usability and learning.

## 🧾 How to Run

### ▶️ Web Version

1. Clone this repository:

   ```bash
   git clone https://github.com/<your-username>/Scientific-Calculator.git
   ```
2. Open `scientific_calculator.html` in your browser.
3. Use the on-screen buttons to perform calculations.

### 🐍 Python CLI Version

1. Run the Python script:

   ```bash
   python sl_project.py
   ```
2. Follow the on-screen menu to choose operations and input values.
